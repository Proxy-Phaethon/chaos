## what is logic in chaos?
at this point, version 1 of chaos is more like an extremely elaborate calculator more than anything else. but hey, it's a good way to force myself to learn C. i'm trying my best to stop inventing a whole new programming language and instead build a proper tool as well as learn C, C++, and C++11. 

a logic is like a miniature program. it takes one question, knows its rules of implementation, and gives you an answer. that's literally it. it's just a name for a block, like 'int' is in C. you start a block with 'logic' and end it with 'execute'.
