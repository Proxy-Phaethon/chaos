## Programming Language

Status: Research

## Digital Physics

Chaos does not begin with programming languages.

It begins with digital systems.

Programming languages are simply one way humans communicate with digital systems.

Before inventing syntax, understand the machine.

---

## Logic

### Logic 0

Represents absence.

No signal.
No action.
No meaning.

### Logic 1

Represents presence.

Signal.
Action.
Meaning.

### Logic 2

Chaos extension.

Logic 2 is not a hardware state.

It represents information outside binary logic that exists for language construction.

Examples may include:
- intent
- uncertainty
- semantic relationships
- context

The exact definition is still under investigation.

---

## Contracts

Every component should define a contract.

A contract specifies:

- accepted inputs
- produced outputs
- conditions for execution
- expected timing
- guarantees

If a contract is violated, the component should fail predictably.

---

## Combinational Devices

Complex systems emerge from simple devices. A calculator.

Each device should perform one operation.

Examples:

- copy
- invert
- compare
- select
- combine
- transform

Large behaviour should emerge from composition rather than large individual components.

---

## Central Engine - Brain

Every combinational device reports to a central engine.

The engine is responsible for coordination rather than implementation.

The engine should resemble a brain.

Devices resemble organs.

Neither should attempt to perform the other's responsibilities.

---

## The Structure

Chaos will follow a similar structure to how physical systems are built.

Logics, combined, will create a block to add contracts to. Several contractual blocks will create a combinational device, a.k.a. a calculator. Combinational devices, when connected together, create the brain of the system.
